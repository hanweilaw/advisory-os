# Product note format

Every product note follows this layout so `/compare-products` and `/fna` can read it. Each fact cites the page of the source document.

```markdown
# {{Provider}} {{Product}}

Source: {{file name}}, version/date {{}}. Summarised {{YYYY-MM-DD}}.

| Feature | Detail | Source page |
|---|---|---|
| Type | | |
| Entry ages | | |
| Premium term / policy term | | |
| Sum assured / benefits | | |
| Guaranteed vs non-guaranteed | | |
| Charges and fees | | |
| Surrender / early exit | | |
| Riders | | |
| Key exclusions | | |
| Who it suits | | |
| Who it does not suit | | |

Open questions: {{anything the document doesn't say, marked [VERIFY]}}
```
