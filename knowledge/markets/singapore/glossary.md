# Glossary (Singapore)

| Term | Meaning |
|---|---|
| CPF | Central Provident Fund; OA (Ordinary), SA (Special), MA (MediSave), RA (Retirement Account, from 55) |
| BRS / FRS / ERS | Basic, Full and Enhanced Retirement Sums set aside in the RA at 55 |
| CPF LIFE | Lifelong annuity paid from the RA, from age 65 (deferral up to 70) |
| SRS | Supplementary Retirement Scheme, voluntary tax-advantaged retirement account |
| MediShield Life | Basic national health insurance; IP = Integrated Shield Plan on top |
| CareShield Life | National long-term care insurance |
| LPA | Lasting Power of Attorney |
| ACP | Advance Care Planning |
| TPD / CI | Total and Permanent Disability / Critical Illness |
| ILP | Investment-Linked Policy |
| IUL / VUL | Indexed / Variable Universal Life |
| CKA / CAR | Customer Knowledge Assessment / Customer Account Review |
| FNA | Financial Needs Analysis (fact-find) |
| DPI | Direct Purchase Insurance |
| NRIC / FIN | Identity numbers; mask to the last 4 characters in working files |
